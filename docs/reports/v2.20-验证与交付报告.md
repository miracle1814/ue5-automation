```cmd
:: ① 依赖（会自动尝试部署 bridge；非 5.1 引擎会被版本闸拦截并给出指引）

:: ② 手动部署 bridge（推荐项目级；--auto-engine 装到引擎目录需管理员）

:: ③ UE 配置：启用 Python Editor Script Plugin + 勾选 Remote Execution → 重启编辑器
:: ④ 验证
cd skill\ue5-automation\scripts
python check_ue_version.py          :: 30 秒版本自检（0=5.1 可用）
python ue5_runner.py health         :: 链路健康检查
```
