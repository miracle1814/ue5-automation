## 七、v3.2 收口补丁 —— 前置解析守卫的 GameThread 分流（P0 崩溃修复）

> 2026-09-18 晚 · 全量回归 478 passed / 98 skipped / **0 failed**

**现象（P0，实测复现两次）**：`spawn_actor` 等命令的前置解析守卫在 HTTP 线程对
`/Game/` 内容类路径调用 `unreal.load_class` → 触发真实 `LoadPackage` →
引擎断言 `IsInGameThread()` fatal → **编辑器直接退出**。非 GameThread 线程加载
资产包在 UE 中非法；`/Script/` 引擎类路径只做内存查找不触发加载，故此前未暴露。

**修复**（`ue5_bridge._pywrap_try_load_path`，按路径分流）：
- `/Game/` 内容路径与无前缀短名 → 一律投递 GameThread 执行
  （复用 `_run_on_game_thread_sync`，15 s 超时 fail-loud 并提示）；
- `/Script/` 引擎类路径 → 调用线程直呼（纯内存查找，无加载风险）；
- `TEST_MODE` 离线替身 → 一律直呼（无 tick worker，投递必超时）。

**附带修正**：publish.py 的 5.1 DLL 期望尺寸常量 828,416 → 901,120
（v3.1 起 UMG 回读 API 使 DLL 增容，清单 `size_match` 由此恢复 True）；
manifest 随本补丁重生成（ue5_bridge.py MD5 `337028ED…` / 463,879 B）。
