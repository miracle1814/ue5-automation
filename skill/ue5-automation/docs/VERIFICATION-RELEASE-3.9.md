## 三、已知边界（不影响发布，使用前须知）

| 边界 | 说明 | 影响 | 处置 |
|---|---|---|---|
| **Pillow 不在编辑器进程内可用** | 引擎 Python 自带环境 import PIL 失败（DLL 名冲突，B12） | 截图不能画 actor 名标注；>768px 不压缩、只回路径 | 设计内降级：跳过标注 + 告警 + PNG 结构解析兜底（已真机自证）。需要标注时改用宿主解释器后处理 |
| **`bBeingCompiled` 守卫不可用** | 该标志为 transient 位域，5.1/5.8 Python 包装器均不暴露（B16，debug_reflect 定案） | 无法检测"编辑器正在编译" | 实际防线 = 全部写操作经 GT 队列串行化；守卫本就只防外部异步编译 |
| **`apply_graph` 对 bool 引脚不做数值转换** | float/int → bool 的边会在写入层被拒（事务回滚） | spec 里这类边写不进去 | 正确行为（UE 语义如此）。写 bool 前先在 spec 里用 Branch/Comparsion 之类节点显式转换 |
| **诊断的 `errors` 含日志窗口历史行** | `errors` = 日志尾部 200 行的结构化提取，与编译结论独立 | 修复收敛后 `errors` 仍可能非空 | **收敛判据用 `compiled`/`compile_status`**，不要用 `errors` 为空 |
| **标题级连线对同名节点会拒绝** | 节点标题歧义时 fail-loud 并列出候选 GUID | 需要按 GUID 指定 | 这是防连错设计；用 `search_blueprint_nodes` 拿 GUID |
| **编辑器被最小化后可能自行退出** | 演练中最小化+PIE 组合触发了编辑器退出（1 次复现，未深挖） | 长时间无人值守会中断 | 建议保持窗口可见；不属于桥的问题（PIE 帧也同时停了） |
