## 4. 使用边界（必须向用户讲清）

1. 编译通过 ≠ 行为正确：用 `verify_behavior` 断言属性/截图；仍无法证明"逻辑符合主观预期"。
2. 撤销只覆盖 agent 事务；用户穿插操作会让回滚提前停。
3. 资产回滚是文件级恢复；两引擎均无 `reload_asset`，恢复后需重启/Rescan。
4. AnimBP/UMG 之外的领域（Niagara 等）不在范围内。
